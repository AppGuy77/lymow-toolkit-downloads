## Away-from-home access moved to new infrastructure

Your permanent away link keeps working exactly as before — save it once, use it from anywhere. This update
changes how that link reaches your Toolkit behind the scenes so it keeps working for everyone, including
brand-new installs that the previous system had started turning away. There is nothing to set up: sign in
and your link reconnects on its own within a few seconds.
